# TAN_COFFEE_WEBSITE

A bespoke e-commerce storefront for **Tan Coffee**, featuring:
- Customized **TAN** serif branding and art deco winged logo
- Warm Biscuit (`#EEDCBA`) and Rich Maroon (`#6E1A24`) global theme palette
- High-fidelity product packaging visuals with custom-stamped pouches and clips
- Fully responsive navigation, hero banner, product showcases, newsletter, and footer
